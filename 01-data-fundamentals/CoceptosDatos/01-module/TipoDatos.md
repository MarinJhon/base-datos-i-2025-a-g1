#Bases de datos

los analistas de datos trabajan con base de datos  lo que son colecciones organizadas de datos estructurados en un sistema informatico  que permite almacenar y acceder a la informacion ,  la gran mayoria de base de datos son relacionales lo que significa que organiza la informacion en varias tablas vinculadas entre si lo cual facilita a la gestion y el analisis de los datos permitiendo conectar diferentes grupos de informacion.

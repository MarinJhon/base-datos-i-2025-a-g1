la visualizacion de datos nos permite representar informacion compleja de manera grafica para facilitar aun mas su comprension son herramientas esenciales para los analistas de datos .
 los graficos y mapas simplifican informacion compleja y hacen que los datos sean mas accesibles  ya que un solo grafico puede responder multiples preguntas

 Por qué el diagrama de Tufte es una buena visualización?

 el diagrama de tufte  es una excelente representacion de datos por que combina multiples variables en una sola imagen de manera clara y efectiva
 muestras seis tipos de datos ( tropas distancia , temperatura, coordenadas , direccion y fechas)
 es intutivo y facil de interpretar   integra contecto geografico  .

 Cuente una historia de datos convincente

 la narracion de datos trasforma numeros en historias comprensibles y persuasivas ayudando a tomar decisiones para ser efectiva debe combinar datos visualizacion y narrativa 
 cuando se combinan estos elementos los datos dejan de ser solo numeros y se forman herramientas poderosas para impulsar cambios y tomar mejores decisiones.

 mejor grafico

  es importante saber el tipo de datos ya que cada tipo de grafico maneja una funcion
  grafico de barra , grafico de lineas ,  grafico circular , diagrama de dispersion.

  al elegir el grafico correcto los datos se comunican con mayor claridad y permiten tomar mejores decisiones

Los datos pueden ser engañosos

si la visualizacion s emanipula de manera que distorsione la interpretacion. algunos ejemplos de malas practicas en graficos son
ejes truncados , uso incorrecto de porcentajes , graficos 3d innecesarios , seleccion sesgada de datos 
lo cual es importante pues diseñar una visualizacion de  manera clara objetiva asegurando que represente la infromacion de forma clara

Paso 1: Comprensión del negocio

Todo proyecto comienza con entender el problema que se debe resolver antes de explorar datos.
 El patrocinador empresarial lidera el proyecto, presentando el problema y apoyándolo.
 Se puede aplicar pensamiento de diseño, una metodología centrada en el usuario, para definir el problema, establecer objetivos, desarrollar personajes de usuarios y documentar requisitos.
 Una vez definido el problema de negocio, el científico de datos elige un enfoque analítico, como modelos estadísticos o de aprendizaje automático, para resolverlo.

 Paso 2: Exploración y preparación de datos

 Los científicos de datos identifican, recopilan y preparan datos para su análisis. Las fuentes pueden incluir archivos estáticos (hojas de cálculo), bases de datos e Internet.

 Exploración de datos

Se analizan patrones y relaciones iniciales.
Se evalúan características prometedoras para el análisis.
Se ajusta la hipótesis si es necesario.

 Preparación de datos

Se limpian, combinan y organizan los datos para el modelado.
Se identifican problemas como valores incorrectos, datos corruptos o valores atípicos.
Se utilizan herramientas automatizadas para procesar grandes volúmenes de datos con precisión.

Paso 3: Representación y transformación de datos

En esta fase, los científicos de datos aplican diversas técnicas matemáticas y estadísticas para analizar y transformar los datos con el fin de extraer información valiosa.

 Estadísticas descriptivas

Número (N): Total de observaciones.
Media: Promedio de los valores.
Mediana: Valor central en un conjunto ordenado.
Moda: Valor más frecuente en los datos.
Mínimo y máximo: Extremos del conjunto de datos.
Desviación estándar: Grado de dispersión de los datos respecto a la media.

Paso 4: Visualización y presentación de datos

a visualización de datos es la fase en la que los científicos de datos representan gráficamente los conocimientos obtenidos a partir del análisis y la transformación de datos.
 Importancia de la visualización

Permite probar hipótesis y validar suposiciones.
Facilita la comprensión de los datos para la toma de decisiones.
Debe contar una historia clara y responder a la pregunta o problema planteado en el proyecto.
Objetivo

Crear visualizaciones efectivas, atractivas e impactantes.
Tipos de visualización de datos
Dependiendo del objetivo, se pueden usar diferentes representaciones gráficas, como:

Gráficos de barras: Comparar valores entre categorías.
Histogramas: Mostrar la distribución de datos.
Diagramas de dispersión: Identificar relaciones entre variables.
Mapas de calor: Visualizar la densidad de valores en un conjunto de datos.

Paso 5: Entrenar modelos de datos

Un modelo de datos es una representación estructurada de los datos, sus atributos y las relaciones entre ellos. Su propósito es reflejar un escenario empresarial real para facilitar el análisis y la toma de decisiones.

¿Por qué crear un modelo?

Permite un enfoque sistemático para resolver problemas empresariales.
Mejora la capacidad de predicción en los negocios.
Ayuda a comprender mejor el sistema analizado.
Uso del aprendizaje automático:

Los modelos se entrenan con algoritmos de aprendizaje automático.
En lugar de seguir reglas programadas, la máquina aprende a partir de datos.
Cuantos más datos procesa un algoritmo, más preciso se vuelve en sus predicciones.

Paso 6: Implementar modelos de datos

 Pasos clave en la implementación:

Guardar e integrar el modelo en la infraestructura de la empresa.
Configurar su ejecución, ya sea por lotes o en tiempo real.
Monitorear y evaluar su desempeño en producción.
Planificar el mantenimiento, asegurando su precisión a lo largo del tiempo.
 Preguntas que debe hacerse un científico de datos:

¿Cómo se medirá el rendimiento del modelo en producción?
¿Cada cuánto tiempo se debe volver a entrenar o ajustar?
¿Los datos de producción difieren de los datos de entrenamiento?
¿Se ejecutará el modelo en lotes o en tiempo real?
¿Se necesita ejecutar el modelo sin conexión?

¿Qué es una metodología?

Una metodología es una estrategia general que guía las actividades dentro de un proceso. Una metodología no depende de tecnologías ni herramientas, ni es un conjunto de técnicas o recetas.

tres metodologías clásicas y ampliamente adoptadas en ciencia de datos :

Proceso estándar intersectorial para minería de datos (CRISP-DM)
Descubrimiento de conocimiento en bases de datos (KDD)
Muestrear, explorar, modificar, modelar, evaluar (SEMMA).
CRISP-DM , KDD y SEMMA :

Utilizar métodos de minería de datos
Son los más adecuados para datos estructurados.
Son útiles para utilizar análisis descriptivos y predictivos.
Compartir algunas actividades comunes, como recopilación de datos, transformación de datos, modelado de datos y evaluación de modelos.

Los científicos de datos utilizan metodologías para estructurar su trabajo, entre ellas:

CRISP-DM (Proceso estándar intersectorial para minería de datos)
KDD (Descubrimiento de conocimiento en bases de datos)
SEMMA (Muestrear, explorar, modificar, modelar, evaluar)

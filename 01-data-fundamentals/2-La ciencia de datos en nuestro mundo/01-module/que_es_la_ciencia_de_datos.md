Definición de ciencia de datos

la ciencia es un metodo que combina objectivos practicos con leyes cientificas la ciencia de datos aplica este metodo al analisis de datos para comprender el mudno 
es una disciplina que integra el metodo cientifo , matematicas , estadisticas , programacion , ia y narracion de datos para extraer conocimientos ocultos en grandes volumenes de datos
el objectivo principal es obtener el valor de los datos volviendolos en infomracion util para la toma de decisiones .

 Análisis de datos versus ciencia de datos


 aunque trabajan con datos y buscan trasformar la informacion en inteligencia empresarial sus enfoques son disintos

  analisis de datos se centra en recopilar y examinar grandes conjuntos de datos para identificar tendencias realizar pronosticos que faciliten la toma de deciosiones

  ciencia de datos se enfoca en diseñar y desarrollar nuevos procesos para el modelado de datos utilizando algoritmos y estadistica avanzada para organizar datos no estrucutados

Comienza tu proyecto

El proyecto implica utilizar IBM Watson Studio y la herramienta de refinación de datos para:

Aprovisionar el servicio Watson Studio.
Configurar un nuevo proyecto.
Importar y limpiar el conjunto de datos de reclamaciones de seguros de autos.
Refinar el conjunto de datos.
Crear y analizar visualizaciones de datos.
El conjunto de datos es ficticio, basado en registros de reclamaciones aprobadas, con 975 filas y 38 columnas. Cada fila corresponde a una reclamación de una persona que solicitó reparación de un automóvil tras un accidente.

La póliza de seguro de auto es generalmente de seis meses, y factores como el tipo de vehículo, historial del conductor y edad determinan el costo de la póliza. Los conductores con menos accidentes o multas tienen primas más económicas.

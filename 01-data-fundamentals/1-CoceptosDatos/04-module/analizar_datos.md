analisis de datos

el analisis de datos consiste en recopilar limpiar y trasformar informacion para una mejorar toma de decisiones. antes de iniciar un proyecto de analisis es muy clave definir un objetivo y formular las preguntas adecuadas ya que el exito del analisis depende en gran medida de eso. 

 Recorrido con un analista de datos

 charles analista de datos en una empresa de investigacion de marketing  lleva a cabo con su equipo proyectos de analisis de datos / nos dice que un proceso clave en este trabajo es ETL ( extraccion trasnformacion y carga ) que consiste en integrar datos de multiples fuentes en un solo sistema para analizarlo 
 extraer datos de diversas fuentes
 trasformar y limpiar informacion para mejorar su calidad y coherencia
 cargar los datos en una base de datos para su analisis
